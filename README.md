# 赛博朋克指数 / Cyberpunk Index

高科技 × 低生活。CPI = √(T × L)，T、L 均为 0–100。

- 在线查看：见仓库右侧 Pages 链接（`web/` 目录）
- 指标、方法与局限：`web/about.html`，以及 [docs/README.md](docs/README.md)
- 复现：`python code/run_all.py`（需要 Python 3 + pandas，联网下载世界银行和 Our World in Data 数据）
- 结果：`output/cyberpunk_index.csv`、`output/indicator_detail.csv`、`output/sensitivity.csv`

数据来源：世界银行、联合国毒品和犯罪问题办公室（经世界银行）、FAO（经 Our World in Data）。
