# 赛博朋克指数 工作区

定义：高科技 × 低生活。CPI = √(T × L)，T、L 均为 0–100。

## 目录（严格分离）
- `code/`  只放脚本
- `data/raw/`  原始下载（worldbank/、owid/ 各自独立）
- `data/processed/`  清洗后的中间表
- `output/`  指数结果与敏感性分析
- `docs/`  说明文档

## 运行
需要 Python 3 + pandas。在工作区根目录：
    python code/run_all.py
或分步：01_download.py -> 02_clean.py -> 03_index.py -> 04_web.py
`03_index.py` 另输出 `output/indicator_detail.csv`（各国各指标原始值、数据年、0–100 得分）；`04_web.py` 据此生成网页数据 `web/data/cpi.js`，榜单页和明细页都从这里读数据，重跑流程后网页自动更新，无需手改 HTML。
预览网页：`python -m http.server -d web`，或直接双击 `web/index.html`。

## 参考年份
10 个指标在该年**当年**都有数据才可用，缺任何一个指标的年份整体不可用（目前为 2017–2023；"吃得起"数据 2017 起，工时到 2023 止）。不回避疫情年份。
每个快照取 [Y-4, Y] 内各国最新值（并记录实际数据年）。

## 指标
T 高科技（三个子维度等权）：渗透（互联网使用率、固定宽带/百人） | 投入强度（研发占GDP、每百万研究人员(log)） | 产出规模（居民专利、科技论文、高技术出口额，均为占世界总量份额，不取对数）
L 低生活（七个维度等权）：基尼系数(WB) | PM2.5(log, WB) | 凶杀率(log, WB/UNODC) | 买不起健康饮食人口比例(FAO/WB via OWID) | （人均自付医疗支出/人均GNI(PPP, WB) + 5岁以下死亡率(log, WB)，两项等权合成"看得起病"） | 预期寿命(反向, WB) | 年均工时(OWID)
- 缩尾 5%/95% 后线性缩放到 0–100；T 内子维度等权。总量指标在每个快照内先换算为占各国总和的份额（config.SHARE_KEYS）。
- L 八项指标必须齐全才入榜；T 至少 70% 指标有数据（七项中至少 5 项）。
- 敏感性：调和平均、min、1%/99% 缩尾，见 `output/sensitivity.csv`。

## 已知局限
世界银行/联合国无台湾单列；各国数据年份不一；低收入国家工时为模型估计；暂无可比的全球住房负担数据；所有指标都与发展水平相关；产出规模按总量份额，偏向大国。
